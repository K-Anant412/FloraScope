# FloraScope — Plant Identification & Care Guide

FloraScope is a full-stack web application designed to identify plant species from uploaded images or camera snaps. It delivers comprehensive botanical information, including customized care instructions, pet and human toxicity warnings, and documented medicinal uses.

---

## Features

* **Image-Based Identification:** Upload a photo or capture an image via mobile/desktop camera to identify plant species using the Pl@ntNet API.
* **Care Guides:** Quick-reference indicators for light requirements, watering schedules, temperature tolerance, and soil preferences.
* **Toxicity & Safety Alerts:** Clear visual indicators for cat, dog, and human safety hazards.
* **Medicinal & Traditional Uses:** Contextual insights into traditional usage, herbal properties, and precautions.
* **Search & Query:** Search plant records directly by common or scientific names.

---

## Tech Stack

* **Frontend:** React, Tailwind CSS (or HeroUI / Mantine)
* **Backend:** Python (Flask), RESTful API Architecture
* **Database:** MySQL
* **APIs Integrated:** Pl@ntNet API, Wikipedia REST API / Perenual API
